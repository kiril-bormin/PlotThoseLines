Logiciel simple permettant de visualiser des données de capitalisation boursière des entreprises mondiales.

Fonctionnalités :

- Ajout de plusieures courbes sur un seul graphique
- Possibilité de masquer/supprimer les jeu de données souhaitées
- Export de tranche de temps souhaité en une image .png
- Ajout d'un jeu de données complémentaire à une serie existante (le nom de fichier allant jusqu'au premier tirez du bas est pris en compte. Ex: dans un fichier au nom "AAPL_daily_market_cap_20y", seulement le texte avant le premier tirez du bas "_" sera pris comme l'acronyme de l'entreprise, soit "APPL").
